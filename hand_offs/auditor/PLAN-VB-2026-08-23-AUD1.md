**Program rules (binding, ported from tennis + volleyball-specific):**
1. Rule 3 bytes-only: no row without a named, checkable source URL; per-row provenance.
2. Schema + harness locked in WO-VB-0 **before any row is written**; any later change = disclosed migration.
3. Every work order runs 3-phase: PRE-AUDIT (state recovery + baseline + per-event census) → WORK (build) → POST-AUDIT (harness + summaries + commit-verify + REPLY doc).
4. 2026 editions are built only after their final is played (post-event queue); no live half-built editions in the store.
5. Cold-start trackability: `PROGRESS-VB.md` ledger (this commit) is the single resume-point — any fresh session reads it and knows exactly what is done, in flight, and next. Every WO closes by updating it in the same commit.
6. Store-existing canon wins for team names (once first written); country teams use full English names ("Türkiye" policy decided at WO-VB-0 — one spelling, locked).

## Row schema v1 (proposed — locked at WO-VB-0 sign-off)
```json
{
 "date": "2023-09-03", "competition": "EuroVolley_W", "tier": "CONT-CH",
 "gender": "W", "phase": "Pool B", "round": "RR",            // RR | R16 | QF | SF | F | 3P | 5-8 etc.
 "teamA": "Turkiye", "teamB": "Italy", "winner": "A",        // teamA ALWAYS the match winner (tennis convention)
 "bestOf": 5, "setsA": 3, "setsB": 1,
 "set_scores": "25-20 23-25 25-16 25-19",                    // authoritative token string
 "pointsA": 98, "pointsB": 80,                                // derived, harness-checked
 "duration_min": "", "forfeit": false, "golden_set": false,
 "edition_year": "2023", "venue_city": "Brussels",
 "source": "<official match URL>", "status": "completed",     // completed | forfeit
 "provenance": {"capture_agent": "Auditor 1 - arena/01a015bb-the-creation-2", "capture_date": "<real date>",
   "ssot_write": true, "note": "WO-VB-N build per PLAN-VB", "merge": "WO-VB-N-<EVENT>-<DATE>", "raw_source": "<byte narrative>"}
}
```
**Harness v1 (volleyball arithmetic — replaces tennis game-parser):** winner==A always; setsA==3 (unless forfeit convention differs), setsB∈{0,1,2}; token count == setsA+setsB; sets 1–4 valid iff winner-side ≥25 and (diff==2 exactly when loser ≥24, else winner==25); set 5 same with 15; pointsA/B == token sums; forfeit rows: status forfeit + FIVB 25-0×3 or federation-recorded scoreline, wire-sourced narrative; golden-set rows (CEV qualifiers only) flagged, excluded from sets arithmetic; date-year == edition_year prefix; duplicate (phase,round,pair) guard; completeness == official match count per edition (byte-derived per census, never assumed — pool-of-6 = 15 matches/pool etc.); MANIFEST sha256/count/status sync; store count == Σ editions.

## Source-of-truth hierarchy (locked)
1. **CEV.eu match centre** (CEV events) / **volleyballworld.com** (FIVB events: WCh, VNL, Olympics results mirrors) — set-by-set authority.
2. Confederation sites (asianvolleyball.net, norceca, CSV, CAVB) for their championships.
3. Wikipedia edition pages — cross-check + completeness template only (they carry full set scores; usable as secondary corroboration, never sole source for a disputed row).
4. Wire (Reuters/olympics.com/federation news) for forfeit/withdrawal narratives. Grokipedia: rejected class (2 strikes logged).
